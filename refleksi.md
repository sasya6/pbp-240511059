# Refleksi

Menurut saya, platform Web merupakan platform yang paling menarik untuk dipelajari karena dapat digunakan untuk membuat berbagai aplikasi yang bermanfaat dan mudah diakses melalui browser. Saya ingin mempelajari lebih dalam cara membuat website yang interaktif dan dapat membantu menyelesaikan permasalahan sehari-hari.

Tantangan terbesar saat melakukan setup environment adalah memastikan semua tools terpasang dengan benar dan dapat dijalankan melalui terminal. Terkadang, perintah tertentu tidak dapat digunakan karena masalah instalasi atau pengaturan PATH pada komputer. Hal ini membuat proses persiapan membutuhkan ketelitian dan kesabaran.

Untuk mengatasi tantangan tersebut, saya akan mengikuti petunjuk instalasi dari dokumentasi resmi, memeriksa kembali konfigurasi setiap tools, dan mencoba menjalankan perintah versi untuk memastikan semuanya berfungsi. Jika masih mengalami kesulitan, saya akan mencari referensi tambahan atau bertanya kepada dosen dan teman yang lebih memahami. Dengan demikian, saya berharap dapat lebih memahami lingkungan pengembangan dan menggunakannya untuk mengerjakan proyek pemrograman berikutnya.
