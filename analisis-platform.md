# Analisis Komparatif Platform

## 1. Web, Desktop, dan Mobile

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | Java, C++, C# | Kotlin, Java, Swift |
| Arsitektur | Browser dan server | Sistem operasi komputer | Sistem operasi perangkat mobile |
| Cara distribusi | Melalui browser dan URL | Installer atau toko aplikasi | Play Store atau App Store |
| Keunggulan | Mudah diakses melalui browser | Dapat berjalan langsung di komputer | Praktis digunakan di mana saja |
| Keterbatasan | Fitur tertentu bergantung pada browser dan jaringan | Perlu instalasi dan penyesuaian sistem operasi | Terbatas oleh ukuran layar dan sumber daya perangkat |
| Contoh aplikasi | Google Docs versi web | Microsoft Word desktop | WhatsApp mobile |
